# docs 目录导航

入库文档只保留「公开面」：README/官网引用的素材 + 面向协作者的开发文档。

## media/ — 图片与演示素材
README 与官网使用的截图与动图。文件名前缀对应 README 章节（`01-today.png` 等）。

## 开发文档
- `开发规范.md`:工程约定（CSS 架构/三禁止/并行纪律/目录契约）——改动方式、新增依赖、目录契约的权威说明
- `refactor-plan.md`:两大架构重构（样式体系统一、组件层 SFC 化）的立项说明与状态追踪
- `数据升级检查清单.md`:schema 迁移与数据升级的检查清单（涉及 todos_v2 列语义化时必读）

## 内部资料（不入库，本地维护）
工作过程中的研究资料、策略文档与流程文件统一放在本地私有目录，不属于本仓库的公开内容。

## 约定
- 截图更新：改 UI 后按 README 引用顺序重新导出到 `media/`
- 新增文档先问一句"这适合公开吗"——不适合的放本地私有目录，不要进 docs
- 新增子目录/文档请在本文件登记一行说明
