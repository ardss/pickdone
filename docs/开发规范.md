# 开发规范 —— 为什么每次都有新问题，以及现在如何系统性杜绝

> 本项目反复出现「改一处坏一处」的根因是结构性而非偶然的：无构建步骤（没有编译器查错）、
> 无 lint（引用不存在的函数要到运行时才炸）、无 commit 门禁（坏代码直接进仓库）、验证靠人肉。
> 2026-08-28 起以下防线全部落地，**历史事故类别已逐条映射到具体检查项**。

## 一、日常命令

| 命令 | 作用 | 何时跑 |
|---|---|---|
| `npm test` | 单元测试（纯函数 16 断言） | 改 utils/store 逻辑后 |
| `npm run smoke:cli` | CLI 冒烟（隔离库，不碰真实数据） | 改 CLI/DB 语义后 |
| `npm run smoke:ui` | UI 冒烟回归 + axe 无障碍检测（需先启动隔离实例：Git Bash `TODO_USER_DATA_DIR="$(pwd -W)/.dev-data" npx electron . --remote-debugging-port=9333`；PowerShell `$env:TODO_USER_DATA_DIR="$PWD\.dev-data"; npx electron . --remote-debugging-port=9333`；或直接 `npm run app:dev -- --remote-debugging-port=9333`） | 改组件/视图/布局后 |
| `npm run lint` / `lint:fix` | ESLint 检查 / 自动修 | 随手 |
| `npm run check` | lint(0 error) + 单测 + CLI 冒烟 全链路 | 提交前最终确认 |
| `npm run it` | UI 集成测试（自拉起 Electron 隔离实例，UI→store→DB 全链路 5 场景） | 改动交互/store/DB 后 |
| `npm run check:all` | 指纹+许可证+token+i18n+lint+单测+Vite构建+vue-tsc+UI集成+端到端+CLI冒烟等 25 项体检 | 发布前/里程碑 |

## 二、数据目录隔离（红线）

**不带隔离启动的 Electron 实例 = 你的真实用户数据（%APPDATA%\pickdone）。任何测试/冒烟/演示实例一律禁止连接真实数据。**

- `TODO_USER_DATA_DIR`（Electron 实例级）：主进程 `app.setPath('userData', ...)` 整体隔离，App 与内置 CLI 都落到该目录。`npm run app:dev` 即用它把数据定向到 `pickdone/.dev-data/`（已 gitignore），目录不存在会自动创建。
- `TODO_DB_DIR`（CLI 库级）：只影响 CLI/脚本的库路径。优先级：CLI 侧 `TODO_DB_DIR` 优先；未设置时也接受 `TODO_USER_DATA_DIR`（与 App 同目录），保证同一实例内 App 与 CLI 看到同一份数据。
- 手动启动隔离实例（调试端口 9333）：
  - Git Bash：`TODO_USER_DATA_DIR="$(pwd -W)/.dev-data" npx electron . --remote-debugging-port=9333`
  - PowerShell：`$env:TODO_USER_DATA_DIR="$PWD\.dev-data"; npx electron . --remote-debugging-port=9333`
- 演示数据 `--seed-tomato` **只允许在隔离实例（TODO_USER_DATA_DIR/TODO_DB_DIR 已设置）使用**，禁止对真实库注入演示数据。

`npm start` / `npm run dev` 保持直连真实数据（日常自用），开发与测试一律用 `npm run app:dev`。

## 三、commit hooks（已自动生效）

- `npm install` 时自动执行 `git config core.hooksPath .githooks`（prepare 脚本）。
- pre-commit 四道闸（token/语法/lint/单测），**只检查本次提交涉及的文件，秒级完成**：
  1. `node --check` 所有变更 .js/.mjs —— 拦截语法损坏（历史：转义反引号污染、字符串被塞裸换行）
  2. `eslint --quiet`（0 error 放行，warning 不阻塞）—— 拦截「引用未定义的标识符」类事故
  3. `npm test` 单元测试（tests/run-all.mjs 自动发现 *.test.mjs，新测试文件零登记）—— 拦截纯函数语义回归
- 模板层与整页行为无法静态检查，由 `smoke:ui` 兜底；**涉及视图/组件的提交，推送前请跑一次**。

| 历史事故 | 防线 |

| 待办箱删除失效、清空回收站抛错（未导入/未解构） | eslint no-undef（2026-08-28 首轮即抓出） |

## 五、编码约定（违反会被 hook 或 review 拦下）

1. **import 必须写全 `.js` 扩展名**；npm 包一律走 UMD 全局或 node_modules 相对路径（无 bundler）。
2. **模板引用的标识符必须在同组件 methods/computed/data 中真实存在**——Vue3 运行时模板编译期不检查，render 时才炸且表现为整页空白。新增「模板+方法分离」改动后必须 smoke:ui 实测。
3. **视图类显隐从 `$route.name` 推导**，不从 store 标志读（直达 URL/刷新会滞留）。
4. **暗色覆盖集中追加 `assets/css/theme-dark.css` 末尾**，不散改 original-*.css；颜色候选先用对比度公式算（≥4.5:1）。
5. **动态 aria-label 用 `:aria-label` 绑定**，静态属性里 `{{}}` 不求值；装饰性 SVG 统一 `aria-hidden="true"`。
6. **防御性 `try{}catch{}` 允许**（eslint 已放行），但 `$confirm().catch()` 后不得继续执行删除逻辑。
7. **改完必跑**：`node --check`（hook 自动）+ 相关测试；批量改动分批提交，提交前 `git status --short` 核对。
8. **模板绑定的状态必须放 data()**，`this._xxx` 私有变量不能进模板。
9. **运行时校验过的修复随手补单测**：纯函数（utils/*）一律先写失败用例再修。

## 六、已知限制

- Vue template 字符串无法被 eslint-plugin-vue 静态解析（本项目为运行时模板编译），模板正确性靠 smoke:ui + axe 运行时兜底。
- `npm run smoke:ui` 需要应用以调试端口运行且无其它调试客户端抢占（并行会话会互相干扰，脚本已内置重试与看门狗）。
- axe 检测当前覆盖今日视图；其他视图可按需在 smoke:ui 中复制该段扩展。

## 七、单一真源约定（2026-08-30 定稿：同一事实只允许一处定义，其余派生）

| 事实 | 唯一出处 | 禁止 |
|---|---|---|
| 版本号 | package.json → main 进程 `app.getVersion()` → 环境变量 → preload `todoAPI.version` → core.js `appVersion()` | 任何文件再写死 `x.y.z` |
| 测试清单 | `tests/run-all.mjs` 自动发现 `tests/*.test.mjs`（e2e 除外） | package.json/check-all 手写文件清单 |
| 打包白名单 | `scripts/build-whitelist.mjs`（按 lock 闭包生成） | 手工增删 build.files 的 node_modules 条目 |
| 缓存戳 | `npm run bump` 一条命令 bump renderer/index.html 全部 `?v=` | 手改个别时间戳 |
| 日期格式串 | core.js `FMT` 常量 | 模板/逻辑里写 `'YYYY-MM-DD'`、`'M月D日'` 字面量 |
| 品牌名 | i18n `app.name` / 主进程 `i18nM.mt('appName')` | 组件硬编码任何形式的应用名（含历史曾用名，check:fingerprint 第七类规则拦截） |
| 完成反馈 | `utils/completeAction.js`；删除撤销 `utils/confirm.js` | 视图自造 undo toast（Vue2 `on:{click}` 写法在 Vue3 下点击静默失效） |
| 渲染层错误出口 | `utils/logger.js`（installGlobalErrorCapture 已在 main.js 接线 → renderer.log） | 各处裸 console.error 代替上报 |
| CI 与本地门禁 | CI 跑 `npm run check:all`，与本地同一套 | CI 只跑子集（--no-verify 提交无兜底） |
| 弹窗渲染 | ui-smoke [5.8] 开设置遍历页签+编辑面板，断言零 Vue 错误 | 只测视图导航不开弹窗（设置三连 bug 根因） |

## 八、产品原则（新增功能先过这三条）

1. **心流铁律**：番茄专注进行中，任何功能不得产生弹窗、toast、跳转类打断；提示一律「环境化」（既有位置上的变色/角标/文字），且只允许出现在阶段切换的间隙。
2. **不做价值判断**：产品不内置「正常量」类普适标准（如「一天 8~12 个」）。涉及目标/基线时，只对比用户自己的历史（滚动均值）或用户显式设置的值（如「每日番茄目标」设置项，默认 8 仅为占位，文案保持中性）。
3. **记录不审问**：放弃/中断等负面事件静默落账（可选原因输入框、可留空），只在复盘页呈现，不追问、不弹评估问卷。原因文本是纯数据，为未来 AI 复盘预留。
