# 开源路线下的多设备同步 + 付费模式调研报告

日期:2026-09-15
范围:开源 todo/效率应用的同步变现先例(本领域)、跨领域开源应用先例、开源协议与防白嫖机制、结合 PickDone 数据层现状的落地方案。

---

## 一、核心结论(TL;DR)

1. **开源 + 收同步费是被反复验证的路,且本领域有活着的先例**:最贴近我们的是**思源笔记**(AGPL 客户端全开源、本地永久免费、云同步订阅收费,单人/双人团队靠这个活)和 **Tasks.org**(GPLv3,自有云同步 $30/年)。跨领域有 Joplin、Anytype、Ente、Vikunja、Bitwarden。
2. **共识形态**:客户端全开源 + 本地功能永久免费 + 同步服务收费(托管便利性收费),同时**保留免费自托管出口**(自托管服务器或 WebDAV/S3 自带云)。免费出口是泄压阀,不伤付费转化,反而给隐私人群安全感。
3. **技术共识**: profitable tier 没有一家用 cr-sqlite(已停滞)。可行的是**自研 oplog 式加密同步**(思源路线)或成熟的 CRDT 库(Automerge/Yjs/Loro)。服务端可以是哑存储(R2/S3)+ 客户端合并,单人维护成本最低。
4. **协议建议**:客户端宽松协议(MIT/Apache)或 AGPL + **同步服务端 AGPL 开源发布**,只收"运营费"(存储/带宽/可靠性)。AGPL 防公司级白嫖,不防个人自托管(个人自托管正是我们要的)。商标注册 "PickDone" 是真正抄不走的资产。
5. **定价带**(已验证):¥98-148/年(思源 ¥148/年,flomo ¥99/年,TickTick 国内 ¥139/年)或 $30-48/年(Tasks.org $30,Vikunja €40,Obsidian $48);lifetime/买断 ¥300-500 是 AFFiNE($499 Believer)和思源验证过的中国式增强项。

## 三、跨领域先例(笔记/密码/照片同步)

- **Joplin**:AGPL 客户端+服务端全开源;Cloud Basic €2.99/月(2GB)~ Pro €5.99(30GB);免费 WebDAV/Dropbox 同步路径保留至今。教训:免费出口被降级体验会招怨,但"从不撤走免费路径"保住了口碑。启动 Cloud 就是因为捐赠养不起全职。
- **Obsidian**(非开源,但是定价锚):应用免费,Sync 独立收费 $4/月(1GB)/$8/月(10GB)。OSS 社区对它的态度是正面的——"Obsidian 证明用户愿意为同步付钱"是独立开发者的标准论据。
- **Logseq**:付费闭源同步服务端 + 永远 beta = AGPL 社区信任危机,同步可靠性被社区方案(Syncthing/Git)绕过。**教训:卖同步就必须把它维护成全项目最好的组件;卖之前先掂量可靠性工程预算。**
- **Standard Notes**:免费档含无限设备 E2E 同步(被 Proton 收购后依然)——靠高价位功能订阅($90-120/年)转化,背后有公司输血,单人不可复制。
- **Anytype**:本地免费,远端容量收费(免费 100MB 墙,Plus $4/月 1GB);自托管明确免费。窄免费档天然卡在"再存一个附件就痛"的升级触发点,**比 Standard Notes 的宽免费档更适合单人收入结构**。
- **Ente**:AGPL 全开源含服务端,E2E 加密,免费 10GB,付费 $2.49-19.99/月;已实现收入养全职团队。护城河=信任+E2EE。
- **Immich**:靠 FUTO 基金会发工资,荣誉制付费——不可复制。
- **Bitwarden**:客户端+服务端全开源,自托管连付费功能都白送,收入全靠托管云订阅。证明"开源服务端+便宜托管"能规模化,但花了 8 年和一家真公司。

## 四、失败模式与红线

1. **唯一一致的死法:先免费同步后收费/收缩**。Pushbullet 式"免费同步疲劳"引发用户暴动。所有幸存者都是"本地免费、同步从第一天就计量收费"。
2. **闭源服务端在开源社区是可辩护的,但停滞不可辩护**(Logseq)。
3. **免费托管同步无限量 = 永久服务器账单**。思源公开说"8GB 是我们所能承担的极限"——诚实的成本表述反而转化成信任,值得照抄。
4. **中文社区红线**:反弹触发点不是收费本身,而是"阉割免费档"或"收回曾经免费的功能"。把"本地功能永久免费"写在最显眼处。V2EX/知乎对"开源还收费"的敌意,思源式框架("本地永久免费,云服务收费")是唯一被普遍接受的解法。
5. **服务端协议选择**:不要 MIT 服务端(Cal.com 被 fork 出 MIT 版 cal.diy 就是前科);单人规模 AGPL 足够,不需要 BSL。**从第一天加 CLA 或双许可**,给将来签商业托管合作留门。

## 五、PickDone 落地方案

### 商业形态(推荐:思源模式本土化)

- 客户端开源(协议待拍板,建议 AGPL 与思源/我们把持一致),**本地全功能永久免费、无账号**——现状不变。
- **官方托管同步 = 付费服务**:E2E 加密,免费档 25MB+2 设备(后修订:原建议 ≤100MB,商业计划书 v3 统一为 25MB 体验档);**¥98-128/年 或 $30-40/年**;限量 lifetime ¥399-499(早期创始人档,制造稀缺+回血)。
- **免费自托管出口**:同步服务端 AGPL 开源(Docker 一键)+ 或提供 WebDAV/S3 自带云模式。自托管模式可以仿思源对第三方连接器收一次性 ¥60-80 买断——把自托管人群也变成收入而不背服务器账单。
- 收款:LemonSqueezy/Paddle(MoR,全球)+ 爱发电/面包多(国内,激活码制)。
- 定价续费锁价 + 明示成本上限("X GB 是我能负担的极限"),抄思源话术。

### 技术路线

**自研 oplog 式 E2E 加密同步(思源同款思路),不押 cr-sqlite**(已停滞,v2 路线未落地,profitable 层无人使用)。服务端 = Cloudflare R2 哑 blob 存储(<10GB 近零成本零 egress)+ 薄账号(邮箱+token)。合并逻辑全在客户端,服务端读不了数据 = 隐私主张可验证。

### 数据层现状(摸底结论,2026-09-15)

**资产:**
1. 唯一写入口 `db.call()`(`pickdone/src/main/db.js:746`)——IPC/CLI/辅窗全过,已有 `ledgerChangedHook` + `WRITE_OPS` 模式,op-log 捕获几乎白送。
2. todos 已带同步脚手架:`status('add/update/delete/sync')`/`version`/`syncTime`/`updatedAt`/软删 + `commitSyncBatch` 原子 ack + `todosVersion` 游标(db.js:426-452),脏行追踪已建好有回归测试。
3. 加密 SQLite 单文件 + JSON 备份管线(GFS)可复用作快照底座。

**障碍(= 工作量所在):**
1. categories/filters/plan_chips/tomato_records 无 `updatedAt` 无墓碑;`hardDelete`/`filterDelete`/`tomatoRemoveByIds` 物理删不可传播 → 需 schema 迁移 + 删除日志。
2. 无账号体系(auth.js 是假 stub);userId 840001 烤进存量任务 ID;分类 ID = Date.now() 种子,跨设备必撞 → 需 ID 命名空间/UUID 化。
3. settings/habits 是 meta 整块 JSON blob,todo 整行 LWW → 双端并发互相覆盖,需按 plan_chips 先例拆行表。
4. 附件在文件系统(`userData/files`),DB 只存 `local://` URL → 同步需独立文件通道(可放二期)。

### 分期实施

| 期 | 内容 | 性质 |
|---|---|---|
| **P1 数据层地基** | schema 迁移补齐 updatedAt/墓碑/删除日志;ID 命名空间;db.call() 挂 op-log;settings/habits 拆行表 | 纯本地,不碰网络,可先行,也是开源社区欢迎的重构 |
| **P2 合并引擎** | 客户端 oplog 合并 + LWW/字段级策略 + 冲突快照;本地双实例互同步测试 | 纯本地可测 |
| **P3 传输与账号** | 薄账号(邮箱+token)+ R2 加密 blob 上传下载 + 自托管服务端(Docker) | 需要一点基础设施 |
| **P4 商业化** | 免费档容量墙 + 付费档 + LemonSqueezy/爱发电激活码 + 设置页同步 UI + E2E 密钥管理 | 上线收费 |
| **P5 附件与增强** | 附件同步通道、版本历史(Obsidian 式增值点)、多设备管理面板 | 二期增值 |

### 风险清单

1. **同步可靠性成为支持负担**(Logseq 教训)——P2 合并引擎的测试投入要占整个项目最大比重;上线前必须有双设备混沌测试。
2. **付费意愿天花板低**:todo 类应用比笔记类更低(Tasks.org 十年 $30/年),预期收入按"思源级"而非"Notion 级"校准。
3. **协议未定**:开源发布前必须定客户端协议 + 服务端 AGPL + CLA/双许可,否则后补要全员同意。
4. **不能撤免费**:免费自托管出口从第一天保留,定价话术从第一天就是"云服务费"而非"解锁同步"。
